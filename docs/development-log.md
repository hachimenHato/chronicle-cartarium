## 0.2.0-beta.16 · 首次公开发行

提供世界知识库、地图工坊、人物关系、剧情、权限与私有备份。地图连续缩放沿用现有图面即时变换后延迟提交，没有削减地图细节。

发行准备补齐 README、安装说明、0BSD 与完整依赖许可，使用独立白名单源码快照，排除本机数据、凭据、私钥和历史私有运维日志。官方依赖审计发现的 concurrently/shell-quote/source-map-js 问题已更新，审计结果为 0 项已知漏洞；这不代表不存在未知问题。

本机全量 334 项中 330 通过、4 项真实 MySQL 测试显式跳过；类型和正式构建通过。原生 Windows、Linux、macOS CI 的类型、全量测试、构建及 SQLite 安装测试通过；Docker 启动检查通过。首次跨平台验收修正 Docker 缺少导出辅助文件、macOS 更新清单平台枚举问题。增强容器安装/重启/登录检查的最新结果见 Actions。

各系统包携带匹配架构的官方 Node.js 22.23.3/npm，下载校验官方 SHA-256，首次启动需要网络安装锁定依赖。Linux/macOS 归档保留执行权限。无商用规则文本或用户上传素材；四张封面为项目生成插画。

原生 CI 主要覆盖 x64 Windows/Linux 与 Apple Silicon macOS；Linux arm64 和 Intel macOS 安装包仅完成构造与归档校验，不能视为相应实机全面验收。更新、恢复、断电与公网生产部署的完整平台矩阵尚未验收。保持单实例与完整数据备份要求，详见 README、SECURITY 和更新文档。

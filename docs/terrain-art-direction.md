# 地貌填充与古典地图美术

更新：2026-10-16。本文记录beta.14这一轮的参考方向、实现边界及验收入口。实际测试和发行状态以开发日志与handoff为准。

## 参考与取舍

本轮查阅以下作者／机构的一手资料，借鉴组织方法，未复制图章、游戏贴图或第三方资产，也未移植其整套生成器。

- [Wonderdraft](https://wonderdraft.net/)把成组树木、山峰笔刷和统一主题作为地图创作的一部分。采用群落及轮廓变化的思路，让纹理有成片的疏密节奏，避免孤立小图标等距排满。
- [Watabou Perilous Shores](https://watabou.itch.io/perilous-shores)采用程序绘制地图；作者的[河流与森林更新](https://watabou.itch.io/perilous-shores/devlog/1638438/201-small-changes-to-rivers-and-forests)及[山体更新说明](https://watabou.itch.io/perilous-shores/devlog/1563133/190-new-mountains)提供了自然群落和山体样式的参考。只依据公开页面，不声称阅读付费实现细节。
- [Red Blob Mapgen4](https://www.redblobgames.com/maps/mapgen4/)把高程、山脊、水汽与地貌表现联系起来，并混合俯视河岸和侧视山林。采用相同已保存地理场驱动表现的思路，不能另外随机画一层与实际海拔冲突的山脉。
- ETH苏黎世的[地形大形组织](https://ikgrelief.ethz.ch/design/landforms/)、[光照方向](https://ikgrelief.ethz.ch/design/light-direction/)和[尺度概化](https://ikgrelief.ethz.ch/design/generalization/)强调先让主要地势清晰，再增加细节。采用西北光照、宽缓地势与细坡结合、平地克制的明暗，避免把所有表面做成同强度噪声。
- [Inkarnate](https://inkarnate.com/)的纹理与图章分层，以及官方[纹理混合演示简介](https://www.youtube.com/watch?v=DDQavbVKtuA)，支持底色、过渡、装饰分别控制的设计。未观看或还原视频内全部操作，不把公开简介当成内部算法说明。
- [Azgaar官方知识库](https://github.com/Azgaar/Fantasy-Map-Generator/wiki/Knowledge-Base)区分biome、relief与其他地图层。沿用地理数据和美术表现分离，界面切图层不重生成地图。未读取已失效的旧relief-icons.js路径，也不据此描述当前源码。

这些参考并不意味着照搬某个产品的画风。本程序保留低饱和羊皮纸、深浅墨线及既有山峦，新增细节应辅助阅读海陆、地势与交通。

## 绘制组织

`terrain-motifs.ts`集中维护13类陆地生态的原创细纹，各8个结构变体，共104种；变体改变树冠、草丛、沙丘、岩脊等的构图，不把单纯缩放／旋转计作新样式。世界、区域、城镇按尺度调整纹理分布。

`terrain-texture.ts`在全图使用稳定错列采样及连续低频群落，不再为每个行政小单元留白。相同地貌拆成更多格子不应出现人为接缝。真实细海拔负责拒水，最终沿已有海陆／湖岸裁切；道路、河流、聚落和文本的可见对象提供局部留白。隐藏对象不应继续留下空洞。散点最终按地貌合并墨线、浅光和阴影，限制SVG节点与几何预算，不为每棵草建DOM。

`terrain-relief.ts`读取同一保存海拔，以宽／细两级坡向及高程环境构造连续地势明暗，再叠少量生态洗染。等值轮廓共享、连接、平滑并按预算概化；光影与存在的生态类公平分配控制点预算。无细海拔时才退回已有地理单元。组件内不使用额外SVG滤镜、画布截图或栅格底图。

显示顺序是原地表底色 → 专题或政治着色 → 连续地势／生态洗染 → 雕刻细纹 → 已有山林、河路、聚落与文字。古典／区域／国家／文化／信仰图上细纹较轻，地形图更明确；气温、降水、海拔和板块的数值专题不叠额外地貌洗染。可见对象和地理输入由memo缓存，平移继续使用现有浏览器合成表面。

## 数据与限制

新增内容仅为派生显示，不改地理模型、数据库schema、生成配方、随机序列、generationSignature或持久快照。刷新即可展示，不要求重新生成，也不能为了套用美术覆盖用户地图。SVG导出应包含自足的路径和裁切定义。

地貌仍采用既有13类陆地biome，不增加没有生成／编辑含义的假地形类型。它们通过104种细纹和连续洗染获得更丰富的表现；大形仍受原图真实海拔及生成结果约束。低频洗染和纹理是制图表达，不是新的地表模拟。大图初次进入、切到需要绘制地貌的图层和高倍率矢量重绘仍有成本；固定几何预算是显示概化，不能据此宣称任意设备都流畅。

验收包括：同地貌分格无缝、实际水面保护、道路／河流／聚落留白、结构变体覆盖、确定性与输入不变、预算上限，实际生成合成图的古典／地形／区域／国家实图，以及悬停、平移、缩放、保存刷新、逐项隐藏和SVG导出。性能比较只使用3311新临时DemoStore和固定合成地图，不使用实际项目库；累计交互时间不能当FPS。

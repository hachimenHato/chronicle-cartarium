# 地理生成与地图图层

beta.14的地貌细纹、连续地势及生态洗染只从已保存地理场派生，不修改下述生成流程和快照。全图采样避免行政格接缝，按可见河路／聚落／文字留白，原始海岸负责裁切；参考和实现详见[地貌美术说明](terrain-art-direction.md)。

本轮按用户要求重做地图流程，旧地图可废弃，不以复现旧地图外观为验收目标。其他世界、人物、剧情、账号及安装数据不因此清空。地理生成属于确定性的创作近似模型，不等同于地球演化或气象预测。

## 使用流程

1. 创建时明确选择“完全随机”或“按照色块生成”，填写种子、世界／区域／城镇类型、画布尺寸和地理范围。点“选择星球方位与范围”打开可旋转的立体星球：拖动或方向按钮定位中心，＋／－及滚轮支持最深16384倍查看局部（不改变选区）；地方／城镇预设自动聚焦，也可点“聚焦选区”。深度缩放显示局部经纬网与整体定位小球，旋转步长随倍率变小。选择范围预设并拖动两滑条，确认后自动换算经纬端点。取消不改变已有选择；未选择／点“全球”为全星球。既有地图的地理参数也可重新选择，按参数重构后生效。星球上的虚构陆地仅供定位，地图实际距离仍沿用覆盖公里数。
2. 色块来源可先画，也可导入PNG/JPG/WebP。图片只在浏览器解析，不上传原图；14类地形显示HEX、RGB及24位十进制色值。近色采用CIELAB距离，合并同色连通区并保留内湖、岛屿，复杂图片自动降采样，避免每个像素成为对象。三档横条默认B：A最大随机完全不保留形状和大小，仅弱参考方位，重随机大陆面积、偏移和附属群岛，小点也能生成大大陆；B平衡保留部分草稿并以自然变化为主；C严格保形关闭额外岸线扰动，保留已采样海陆／湖泊。创建和后续创作都可改档。已有明确地图轮廓时选C并提高导入解析精度；严格档也受输入采样和生成网格分辨率限制。一般照片也能解析，但建议使用调色板绘制的平面色块图，照片阴影可能被识别为不同地形。
3. 先在色块草稿绘制，再切换生成预览。地形与海拔编辑会影响生成结果。日后打开已保存的地图，直接读取已生成的矢量图、海拔和地理数据；切换展示图层、改名、关联档案、兵棋线不重新执行生成。
4. 地图上方独立按钮栏切换地貌、海拔、板块／大陆架、年均气温、年降水、基础区域和国家／文化／信仰，面板收起仍可切换。选前线／进攻／防御工具或疆域类型不换层；需要显示边界时手动点“区域”。海拔也可从创作工具进入编辑页。参数修改需要点“按参数重新构建地理”；日常修改显示图层不改变参数。重新构建或按同种子重新生成会显式使保存快照失效，保留地名关联并重新计算。
5. 国家／文化／信仰随地图构建生成，优先沿用正确世界与类型的关联／同名条目，再使用未分配的已有条目；不足时由有创建设定权限的账号创建草稿，继承地图的公开／GM属性，与快照一起保存。没有创建设定权限时不越权建立词条，未关联项明确提示。已有设定正文不被地图生成覆盖。「地名与地点」统一五类聚落数量、聚落／大陆／岛／海／湖／省份／街区／疆域／港口／手工标记的名称、定位和关联，也能直接新建对应条目。聚落港共用所属聚落的词条链接，独立沿海码头可单独关联地点词条；解除关联不删除条目。改名称或关联不执行物理生成。
6. “疆域分区”进入选择编辑：选择国家／文化／信仰和目标，单击逐块选取，再次单击取消；Shift＋单击连接两点间的陆地单元；Ctrl／⌘＋单击选择相连同归属区域。检查高亮范围后点“填充选中区域”。“清除归属”只清除当前层，“取消选择”不修改地图。拖动平移，海面与湖泊不能选取；各层独立，无疆域画笔。可以快速新建国家／文化／信仰分区和词条，再选择单元分配归属。高亮只用于编辑，不写入快照或SVG。
7. 港湾优先取聚落附近的真实水面，再按细网格陆地连通分量与沿海国家补足独立码头。每片有可通航外海岸线的大陆／岛屿和每个沿海国家至少一港；码头不占聚落数量，内陆国家不强行设港。仅与当前图框外缘连通的水域视为外海，封闭湖泊不连接海路。海路使用最终细海拔网格寻路，整条连续线都需位于水下；水域连通分量预筛、地形安全圆角与曲线采样避免越陆。保存整米海拔前保留5米水下余量；绘制细虚线，不再对已采样点无约束插值。没有合适港湾、被陆地隔开的港口不强制画线。真实海岸水域遮罩同时避免描边伸入陆地。
8. 「地点与地名」眼睛按钮可逐项隐藏城市／村落／手工城镇标记、港口、道路和海路。聚落建筑与名称整体隐藏，道路包含路基；共用桥栏只在其全部所属道路隐藏时消失。隐藏保存于editor.hiddenFeatures，不参与生成摘要；不删除数据，不是GM权限设置，JSON／MD仍保留并标记隐藏内容，SVG只保留可见图面。
9. 「兵棋推演」的前线拖动沿陆地区域共享边界寻路，不能穿过单元内部；进攻方向为平滑渐变箭带，撤退为虚线方向箭头，防御为连续线与单侧定距防御齿。前线短齿／防御锯齿默认位于绘制方向右侧，绘制后点对应记录的“翻转齿向”交换两侧，闭合线也可交换内外。反转原控制点顺序，不改变边界路径，保存／撤销／SVG保持一致。都是原创SVG表现，参考推演图与HOI4的读图方式，不声称军事标准合规。修改地形后，无法对齐新版边界的前线移除，原编辑可通过撤销恢复；其他军事线保留。

## 数据与实现边界

- `shared/geography.ts`定义参数及地理单元、板块、气候、区域、疆域、港口与航路。`shared/generated-map.ts`定义已接受的生成快照和军事线；`shared/cartography.ts`将其挂到地图编辑数据。
- 已生成快照存于地图`editor_data`，MySQL JSON与SQLite对应JSON内容一起事务保存，没有另建公用业务库或改变任何其他库。JSON创作档案能保留地理数据；MD输出摘要和名字，矢量SVG输出当前展示图层。上传图片仍须同时备份uploads目录。
- 高分辨率地势／河流采样与较少的Voronoi区域网格分离：前者负责地貌水系，后者负责共享边界和分区；不能把小区域颜色视为一张新随机地图。细分密度与地图类型有关。名称属于显示编辑，改变名称不触发物理生成。
- 分区扩张读取真实山脊、坡度、海峡、河流与聚落选址：国家强约束、文化中等并参考国家、信仰较弱并参考文化。共享边适度向附近河道与山脊弯曲，保持相邻单元一致。国界的连续表现路径沿共享边拼接，在三岔处停止，末端补接真实海岸，遇湖泊分段；不会让每条短边重新开始虚线。补接仅用于绘制，持久边与兵棋仍保持共享拓扑。
- 海岸单元的land表示“含可归属陆地”，并不表示整块都是陆地。政治着色、区域网格和选区必须用实际陆地环裁切，海路与鼠标命中必须用细海拔检查；粗单元不能作为水域通行依据。
- 政治地表颜色在山林、河流道路、组件和文字下方，恢复已保存地图时也使用同样顺序。大范围名称按所属区域主轴轻弧展开，聚落字避让真实组件占地，互相拥挤时缩小或省略；位置为显示时计算，不会为排字重新生成地图。派生名称路径和军事图形随SVG自包含导出。调整前线不会自动切换显示层。
- 地形／气温／降水的专题底色在区域接缝作小范围柔化，海岸／湖岸仍用真实陆地轮廓裁切，山林／河路／文字不模糊。地形专题采用独立土色／植被色，水域统一蓝色，图例共源；不会改变作为输入的14色调色板。
- 地形层新增13类原创地貌纹理与真实坡向明暗，少量合并矢量路径位于河路／建筑／文字下；古典与基础区域层使用较轻纹理，地形层更明确。基础区域从共享单元边提取省／地区／街区界，区分弱网格、中行政边和强国界，均沿实际陆地裁切。
- 温度按选择的纬度与海拔计算；降水由海面温度水汽容量、赤道／中纬度雨带、两个输送方向的纬度权重、公里尺度消耗、约20km有效地形平滑、迎风抬升、背风雨影和有限陆地水汽回补计算，不是独立随机涂色。主风基准在中纬度占优，低纬和极地反向占优，次方向代表年均天气变化。海底深度不当作大气坡度；仍无完整季风、洋流和三维大气循环。新七节点固定色阶与当前保存图层范围／采样均值共用真实数值，旧快照不自动重算；详细审查与限制见[气候模型说明](climate-model.md)。
- 海拔保存为整米以控制大小；快照含地形源摘要，地形、海拔、种子、尺寸或相关参数变化才失效。临时笔刷预览不得进入持久数据；过期Worker结果不得覆盖更新的编辑。
- 随机来源上的后画笔刷会融入原随机底图，可造陆、挖水、抬山、铺丘陵与平原；随后海拔编辑最后生效。森林等覆盖还考虑气温约束。旧“寒冷／干旱／温和”快捷气候切换现在同步地理参数中的均温和降水倍率，地理面板可继续细调。
- 新地理模型限制重复装饰的矢量对象预算，并量化坐标、按绘图误差简化轮廓，完整保留海陆边缘、必要地貌与河路骨架。最大精细度仍增加生成和保存耗时，不是每张图都固定同一个大小；预算超限必须报错而非截去地图数据。
- 服务端严格检查容量、有限数值、坐标、内部引用及前线约束。整个创作档案有15MiB UTF-8预算，为API外层留空间，拒绝超限保存并保留旧数据。大量极细地图可接近此限制；不会静默截断。
- shared/map-surface为前后端共用水面契约：沿每条线段的网格交点分段，检查双线性高度二次函数的内部最大值，不用稀疏采样漏掉细岛。服务器拒绝越陆航路、无海拔导航和脱离所属港湾的航线。
- 私密关联按服务端权限投影处理，不能只隐藏按钮。普通用户未获授权的区域名称、关联和分区归属不返回；编辑可见内容时保留隐藏部分，涉及私密分区的几何重生成需要有相应权限。

## 星球视图与环境预览（beta.11）

球面多边形用D3 geoOrthographic／geoPath在地平线闭合裁切，避免背面顶点跳过后直线连接或整个陆地突然消失；虚构陆地仍仅供定位。选区气温／降水／生态小图及陆地统计复用geography-fields与geography-climate，64列低精度预览延后180ms计算，拖动不执行完整地图生成。创建时按当前种子、尺度与陆地格局估算潜在地形；色块尚未生成时不能预测精确海岸和雨影，界面明确说明。已有地图使用保存海拔粗采样，选区和气候参数按本次草稿计算，应用后仍需明确重构。统计为采样陆地最小／最大／平均，主要生态占比只列前四；无陆地则说明为水面气候。

预览与实际共用纬度、6.5℃/km递减、海岸距离、温度水汽容量、主风输送、迎风增雨和背风消耗；低精度采样不保证与最终每个细格完全一致。仍无季节／洋流／完整气象模拟。球面裁切参考[D3地理几何约定](https://d3js.org/d3-geo)、[投影](https://d3js.org/d3-geo/projection)与[路径](https://d3js.org/d3-geo/path)，实际许可证见THIRD_PARTY_NOTICES。

海港上限256，海路512，地理几何总点数180000。需要的港口超过上限明确报错，不静默漏港。水深不足5m不视为可通航，窄海峡、地图裁切和有限点预算可能让部分港口没有航路；不会画穿陆连接来凑数。

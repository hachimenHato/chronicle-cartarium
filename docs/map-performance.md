# 地图浏览性能与验证范围

## beta.18

本版改善滚轮缩放及高倍率平移。完整地形、地势、专题底色与羊皮纸提前绘入浏览器画布；地名、标记、路线与编辑覆盖继续使用原矢量。原始SVG保留命中、精确坐标与自包含导出，不改变生成配方、保存格式或数据库。

缓存按最高400%缩放、当前屏幕DPR和实际适配比例准备，覆盖完整地图及描边/模糊外扩。不是仅截取眼前的画面；拖到其他区域仍有内容。内容、尺寸、DPR、字体或全屏变化时失效，过期解码结果不会回显；手势中保持同一显示方式，离开地图释放资源。

缓存有4000万像素、单边16384像素上限，无法准备时继续用原SVG，不降低地图数据或输出分辨率。单幅RGBA缓冲理论最高约152.6MiB，另有解码及浏览器资源成本，尚未直接测量显存峰。大窗口、高DPR或地图外大量对象可能使用原绘制方式。

首次打开仍需短暂准备。本机2943对象/1260区域合成图的最终测试中，准备约1.7秒，后续重新打开约0.5～0.8秒；手势已开始时延后到松手再启用。最高倍率预渲染后缩小的纹理与边缘采样会更锐利，和原生按当前倍率绘制并非像素完全一致。

相对本次优化前构建，200%/400%首次该倍率拖动的前四个自动化动作累计约424→78ms、286→84ms；12次连续滚轮动作累计降低约55%。这些动作前缓存已就绪，计时包含浏览器与自动化调度，不是物理输入到屏幕延迟或FPS，也不是跨设备保证。100%冷起手有一次约60→68ms波动；没有宣称所有场景更快。

本机类型/构建检查通过；348单元测试中344通过、4项显式MySQL测试跳过。39项地图/悬浮界面场景分批通过，严格使用3311临时演示存储；包含DPR2/400%截图、拖动/缩放/落笔坐标、隐藏/编辑/撤销、上传图片实际像素、全屏、SVG、切图和资源释放。另3次未等缓存的即时拖动检查通过，手势期间不切换缓存。跨平台和桌面最终验证以本版Release及CI为准。

## 更新与回退

缓存仅是可丢弃的显示资源，不进创作档案、数据库或SVG，不需要重生成现有地图。安装升级请按[更新说明](update-strategy.md)保存草稿、验证完整备份并保留数据与上传目录。报告问题时可提供软件版本、浏览器、缩放倍率、屏幕DPR和复现步骤；不要公开私有工作区、完整备份、账号或密钥。

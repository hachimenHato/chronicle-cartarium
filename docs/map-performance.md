# 地图性能说明

beta.16 将连续平移与缩放先应用于现有图面，在短暂停手后提交矢量视图，避免每次滚轮都重新布局整幅 SVG。没有减少地形细节、对象、区域或导出精度。

Windows 本机隔离合成图的配对测量中，12 次滚轮缩放含稳定等待的累计耗时约减少 52%；平移整体耗时接近旧版，首个位移更快呈现。此结果不是 FPS、跨设备性能承诺或超大地图性能保证。复杂地图停手后的矢量提交与完整工作区保存仍有成本。

历史测试：334 项单测中 330 通过、4 项真实 MySQL 测试显式跳过；9 项相关 UI 复验通过，使用 3311 临时演示存储。公开发行后的 CI 结果与当前限制以 GitHub Release 为准。私有原始测量、运行日志与备份不进入源码发行。

# 范例地图与功能入口

更新：2026-10-19。安装时勾选「填充范例内容」得到“月汐诸国”。范例由故事、地图配方、手工地点标记和生成结果共同组成；实际完成和验证状态见开发日志。

## 为什么程序更新后，旧范例看起来没有重画

程序更新会直接更新纹理、布局和工具界面。已经保存的海岸、河路、港口、气候和疆域结果则继续保留，打开或刷新不会因为版本变化就重新生成。这样不会擅自改变用户已经修改、命名或关联的地图。

`generation.version = 2`表示使用第二代生成数据结构，并不表示该地图已运行过每一次新版算法。旧安装的四张范例不会被新安装配方静默替换；当前项目里新增或改过的地图也不会被初始化。

如果希望主动应用当前生成逻辑，可在右侧「疆域分区」或「兵棋推演」展开「地理生成参数」，检查参数后使用「按参数重新构建地理」。这是会改变地形、水系、聚落和疆域的编辑操作，应先备份；可使用地图撤销，但不应把“恢复出厂设置”当成更新范例的方法。

## 功能在哪里

| 要做的事                                                 | 入口                                                                               |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 查看地形、海拔、国家、文化、信仰、区域、板块、气温、降水 | 地图上方「地图图层」按钮；这些按钮只切换显示                                       |
| 编辑国家、文化、信仰的范围及关联                         | 右侧「疆域分区」，按小区域选择并填充                                               |
| 画前线、进攻线、防御线及翻转齿向                         | 右侧「兵棋推演」                                                                   |
| 设置地图方位、经纬范围、气候和港口                       | 「疆域分区」或「兵棋推演」→「地理生成参数」→星球选择器及参数                       |
| 修改聚落、港口、地名、道路和航路的名称、关联或显示       | 右侧「地名与地点」；展开「聚落生成数量」可分别设置，也可在「创作工具」生成选项调整 |
| 色块A／B／C三档与外部色块图片                            | 新建地图时选择「按照色块生成」；随机来源地图会说明当前来源                         |
| 修改地形与海拔                                           | 右侧「创作工具」→「地形／海拔」；三个创作级别控制可用工具                          |
| 点了地点以后找不到其他工具                               | 顶部页签保持可见，可直接切换；地点档案里也有「返回地图工具」                       |
| 查看图例                                                 | 地图底部「图例」展开；工具栏有独立预留区域                                         |

“地图图层”切换是浏览行为。“地理生成参数”和生成选项是编辑行为，两者不能混为一谈。权限不足时，部分编辑操作不会开放；这与地图是否为范例无关。

## 新安装范例的更新范围

新版配方分别展示1800公里世界、240公里边境区域、4公里村落及7公里港区，使用不同种子、局部经纬范围和各自的地形组合；村落和港区采用较低起伏。世界图12处聚落涵盖城市、小镇、村落、城堡、营地五类，区域图10处、村落图2处、港区图5处。数量是生成上限，空间不足时实际可能减少。生成地点的名称／关联与故事条目配合，手工标记作为剧情入口继续保留。

生成地点由算法选择位置，手工标记是作者布置的故事入口，二者不是同一个对象。不能把两个不同坐标的对象冒充同一座城市；同图已标出的地点不再作为另一处同名生成聚落，港区／村落的渡口、船坞等子地点可以关联主体设定。

四图保留既有世界、故事、地图层级和手工标记ID。旧画笔分区不再充当现代选格边界；生成后的国家、文化、信仰使用地理单元和现有故事条目关联。新安装配方只作用于明确选择填充范例的新安装或初始化，不会自动重写已使用的工作区。

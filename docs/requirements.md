# 编年图志 Chronicle Cartarium 需求规格

版本：0.37；建立日期：2026-09-22；更新日期：2026-10-20。本文定义目标和验收方式，完成情况另见 [开发日志](development-log.md) 与 [交接文档](handoff.md)。本次重点为可选登录、安装时多用户设置及板块名称；下列标准不代表已全部实现或通过验收。

### 0.37 登录选择与板块名称

首次安装默认开启登录并要求自行设置主管理员登录名/密码；关闭登录则不要求或生成账号凭据，直接进入，所有可访问者拥有主管理员权限，多用户不可用。安装时另有多用户选项，选择后必须保持登录开启。后台可开启/关闭登录；重新开启必须填写有效的新登录名和密码，关闭时确认当前密码，多用户开启期间禁止关闭。服务端串行校验登录/多用户变更，不能仅禁用前端按钮；失败不能宣称应用成功，普通用户与次级管理员无此配置权限。关闭/重开不删除创作资料或其他用户，旧安装仍默认需要登录。免登录时完整备份的显式下载确认仍然可用。

新生成板块使用确定性文字地名，不显示内部数字编号为名称。已有数字默认名可只读显示为文字名称，无需重新生成或改真实地图；允许编辑名称，地图标注、图例与 Markdown 一致，改名不改变几何、气候或生成签名，后续重构按同编号保留。

公开 README 展示两张真实软件截图，仅使用虚构范例；说明 Windows 桌面/CMD、Linux、macOS、Docker 和源码版本的架构支持、启动方式与实际验证程度，提供 AI 辅助制作说明与免责声明。下载页区分桌面 ZIP 和 CMD ZIP，旧附件继续保留。

### 0.36 地图连续缩放与拖动响应

滚轮和按钮缩放应及时响应，不随每个输入事件重新提交完整SVG视图。可在连续手势中合成同一矢量表面，停止后一次提交最终矢量视图；保留地图对象、纹理、滤镜、生成精度与持久数据，不用删除细节换流畅。缩放百分比随当前手势更新，指针锚点在宽高不等的画布和留白区正确。

连续滚轮、同帧事件、缩放接拖动、拖动接滚轮、重置、切地图、窗口尺寸与全屏变化不能丢失最后视图或恢复过期状态。缩放尚未停下时开始绘制仍需准确记录落笔／松手坐标，SVG导出不含临时屏幕变换。普通拖动不应为询问未启动的编辑工具而反复读取SVG布局。修改前备份程序和实际数据，前后使用同一复杂合成地图测量脚本、布局、绘制与合成准备成本，明确测量范围，不把自动化耗时称为实际帧率。

### 0.35 图例、工具入口与新版安装范例

图例展开后不得遮挡左侧工具栏、标题、缩放、图层开关或底栏。图例按地图面板可用区域约束宽高，长内容可滚动，工具按钮仍可触达；手机、矮窗口及纯地图全屏保持正确。选中地图地点不能让创作、疆域、兵棋、地名和档案页签消失，切页签应退出地点详情且不写地图，另有清楚的文字返回入口。

安装范例按地图尺度示范局部经纬与不同地形，明确五类聚落、稳定命名及故事关联；现代疆域通过地理单元呈现，不能把旧画笔分区当作新的选格边界。随机来源与色块ABC模式的入口差别需说明。更新未来范例不覆盖现有地图或通过初始化清理用户内容；旧快照不自动重算的原因和功能路径写入[范例地图说明](example-maps.md)。

生成配方的JSON对象字段顺序不应影响缓存判断，笔画与路径数组的顺序仍有意义。升级需继续读取有效旧签名，不得因更换判断方式重算或写回旧地图。首次显示、保存、撤销重做及刷新应使用同一精度的海拔显示场，避免轮廓漂移；验证应保留完整几何和无写入断言。

### 0.34 地貌群落与连续填充

森林、草甸、针叶林、热带林、丘陵、裸岩、台地、沙丘、湿地、冰雪、荒地、苔原、稀树草原应有不同构图的细纹，兼有连片群落、疏密和轮廓变化。纹理不能因行政小单元切分而留缝，也不能变成等距图标墙；世界／区域／城镇匹配表现尺度。依同一已保存海拔建立连续大形明暗，保持西北光照和低饱和羊皮纸风格，参考与取舍见[地貌美术说明](terrain-art-direction.md)。

新增细节应保护真实海岸、湖泊、河流、道路、聚落及文字，隐藏对象不留幽灵空白。古典和政治专题保留较轻细节，地形专题更明确，数值专题不混入额外地貌颜色。纯显示变化不写用户地图、不强制重生成；保留SVG导出及已有编辑能力，按节点／几何预算控制新开销，并在固定复杂地图上复验交互。美术效果必须检查完整地图实图，不能只用数量增长代替效果验收。

### 0.33 地貌纹理、气候解释与局部浏览

地形不只由颜色区分：以与实际地貌一致的林冠、草丛、针叶、山脊、丘陵、沙丘、湿地、冰雪等原创纹理和坡向明暗增强可辨识度；沿真实陆地裁切，细节位于河流、道路、建筑和文字下方，延续古典羊皮纸美术，不能堆积重复大图标。基础区域层分清小单元、省／地区／街区和国界，沿已有共享边，不额外猜一套不一致的轮廓。

气温／降水采用有数值阈值的固定色阶，显示当前保存图层的陆地范围与单元采样均值，说明年均单位及计算依据。不能以本图最小最大动态拉伸伪造湿润或炎热，也不能用未应用的表单参数解释旧快照。温度考虑纬度／海拔；降水应避免单一永久风向和高频小地形反复耗水，以风带、双向输送、有效地形和有限再循环改善，同时保留干旱内陆／雨影。模型仍是创作近似，人工林木覆盖优先和经纬／公里尺度独立的限制必须说明。

拖动时保留完整矢量对象、纹理和可交互坐标，可通过浏览器合成图层减少重复重画；松手后正确提交最终视图，同帧连续拖动、取消、滚轮、切图、全屏及尺寸变化不能丢位移或跳变，普通浏览不保存／不生成。星球支持按真实选区自动聚焦与深度缩放、随倍率精细旋转、局部网格和整体定位小图；城镇选区放大后可辨而非一个点，缩放不改变实际经纬范围。

### 0.32 地图交互性能与可靠回退

优化前完成完整数据恢复验证及源码／静态资源散列备份。不得降低地图生成采样、删除细节或取消既有编辑／隐藏／悬浮／导出能力来代替优化。普通悬停、平移和缩放不重新生成或写工作区；减少不变图形的重复渲染／扫描，逐帧合批仍保留每次输入的真实累积效果和最终松手位置。重置、切图、撤销、工具切换不得被延迟的旧预览覆盖。

正式构建独立于本地开发环境，使用生产React运行时，检查真实产物。对固定复杂地图比较脚本开销与图面一致性，并验证保存后刷新、快速绘制、关联悬浮、疆域／兵棋及导出。球面地平线、两极、日期线和极宽极薄选区必须正确裁切；不改变实际范围及气候含义。备份与恢复路径和未验范围记录在[地图性能与恢复说明](map-performance.md)。

### 0.31 沿海交通、显示管理与星球预览

生成港口开启时，以实际细海拔连通陆地与通海水面识别沿海需求：每片有通海海岸的大陆／岛屿及每个沿海国家至少一个港口。内陆国家不强行分配港口，封闭湖泊不当作外海；独立码头不占用用户设定的五类聚落数量。多港口依水域连通、距离及水域路径生成合理航路；连续线段不得穿陆，保持柔和细虚线。不为无法通航的水域伪造连接。容量超限必须提示，不能静默漏掉必要港口。

「地点与地名」允许单独隐藏／显示聚落、港口、道路、航路，包含完整聚落图案、标签及道路路基；隐藏持久化且不触发地图生成。隐藏仅是显示设置，不能当作隐私权限；导出SVG反映可见图面，JSON／Markdown保留内容并标注隐藏状态。独立港口可关联同世界地点词条，聚落港继续共用所属聚落关联；私密投影和写入校验同步。

地图标题、缩放、图层、工具列、图例和底部提示需要留出空间，窄屏可读可操作；地图全屏仍仅显示地图。星球旋转到地平线、两极和日期线时正确裁切陆地和选区；放大缩小仅改变视图，不改变选区。选区提供气温、降水、生态小图及数值说明，复用实际生成的年均气候计算。已有图以保存的地形粗采样预览，新图根据种子及尺度估算潜在地形并明确不确定性；应用选区参与实际生成，不自动重算已保存地图。

### 0.30 气候、星球位置与绘制可用性

地形、年均气温、年降水色层在单元接缝略作过渡；只柔化底色，海陆／湖岸裁切与图面文字、河路和图章保持清晰。地形陆地颜色使用有别于蓝色水域的土色／植被色，图例与实际专题颜色共源；不得改动作为输入的14色地形调色板。

气温受所选纬度与海拔影响。降水参考海面温度决定水汽供给、纬度雨带、物理距离下的连续风向水汽输送、迎风抬升增雨和背风消耗；不能把海底深度当成大气山坡，不能让海面一律同一个降水值。不同采样密度结果应稳定，风向反转后雨影应随之改变。仍是创作用年均近似，不能宣传为完整气象模拟。

创建地图提供可旋转的立体星球选择器，用拖动定位、范围预设和滑条选择大概方位及覆盖范围，不要求手填经纬度。未选择或选择全球时为北90／南−90／西−180／东180；适用于三种地图类型。选区保存南北／东西端点，支持跨日期变更线；经度字段兼容已有配方。已有地图可从地理参数再次选择，明确重构后生效；不得打开地图自动重算。公里范围与画布尺寸仍可独立配置，星球示意陆地不控制生成海岸。

A档按本条覆盖0.29的面积约束：完全忽略色块形状和大小，仅把稀疏方位当弱锚点；重随机大陆面积、偏移、轮廓及附属群岛数量。微小点也可生成大面积大陆；种子仍可复现。B／C保留原定位，默认B不变。聚落数量输入应在窄面板可读；前线／防御线提供翻转齿向，沿原路径反转顺序，保持边界约束／保存／导出和撤销。

### 0.29 地图体验与形态生成

十种图层使用独立于右侧菜单的按钮栏，明示选中状态，适配桌面和手机。选择前线、进攻、防御、疆域类型不得自动换层或退出海拔；图层与工具独立，切层不改领域数据、不重算。国家／文化／信仰使用可辨识的地表着色，地形图章、河路、文字与手绘对象必须在其上绘制并保持原色，不能通过盖半透明整幅色片牺牲清晰度。

兵棋采用原创方向箭带、虚线撤退箭头与单侧定距防御齿，参考正规推演图和HOI4的读图方式，不复制游戏素材或声称军标合规。前线继续精确沿共享边。国家、大陆、海洋等名称按区域主轴轻弧展开，考虑所属范围、真实水域、聚落建筑及其他地名；拥挤时缩小或省略，不能强行叠压。聚落名称同样避让并支持关联词条悬浮／跳转；SVG须自包含名称路径与军事符号。

「地名与地点」统一五类聚落数量、聚落／大陆／海洋／疆域／港口／手工标记的名称、定位和关联，支持新建词条。港口共用所属聚落关联，避免两个互相矛盾的链接。名称与关联调整不生成地图；正确世界／类型校验、GM投影、清链／改名、SQLite／MySQL／MD和JSON均须同步。

色块方式提供可拖动三档横条：A最大随机只参考连通色块相对面积与重心、不保原轮廓，三圆可生三种大陆；B平衡部分参考轮廓，以合理多样的自然形态为主；C严格保留已采样海陆和湖泊，关闭额外随机岸线扰动。默认B，创建与后续创作都可选择，参数与种子持久化。三档解释结果必须统一影响地势、气候、水系和分区，不能仅改显示图。严格保形仍受输入采样与生成分辨率限制；随机来源不受此选项干扰。验收含A形状不敏感与位置面积、B/C保真、种子可复现、各层一致、无重复生成及数据权限。

### 0.28 海路与疆域修正

海路必须以最终细海拔水面为依据，整个连续线段不得穿陆，不能只检查粗区域、端点或中点。航路使用水域约束下的圆角采样，绘制为平滑细虚线。国界在生成分区时就考虑海峡、高山、坡度、河流及聚落；国家、文化、信仰使用不同扩张阻力，不能完成地图后再画随机线。共享边连续拼接后接真实海岸，湖泊、水湾与海面不显示陆地国界。政治着色与选中高亮按真实海岸裁切。

三类分区随地图生成并关联正确世界／类型的已有设定；允许创建设定时，为不足部分建立继承地图公开／GM属性的草稿，与地图原子保存。已有正文不被自动覆盖。后续修改采用点击选择整个基础区域、明确填充归属；拖动只平移，不使用疆域画笔。支持逐块切换、Shift连接、Ctrl／⌘相连同归属组、取消选择和清除当前层归属，保留其他两层。可快速新建对应分区与词条后选择填充。验收含细岛反例、港湾连接、自然障碍影响、三层独立、私密投影、导出排除选择叠层及刷新不重生成。

### 0.27 地理地图生成

创建来源明确二选一：完全随机／按色块；种子、大小、世界／区域／城镇类型可填。色块可从图片近色识别，提供HEX／RGB／24位十进制调色板。板块、海拔、年均气温、降水与生物群落共同影响最终地形及水系；海岸有多尺度不规则细节。统一不规则邻接区域供国家／文化／信仰生成和按单元精细涂改，名称可编辑、关联并快捷创建设定条目。适合的沿海聚落优先为港口，水域可通航时生成虚线海路。提供沿陆地共享边界绘制的前线以及自由进攻、撤退、防御线。所有生成成果、图层和兵棋线保存；打开已有成果、显示层切换、改名不重新生成。用户明确允许废弃旧地图并重新生成，不能据此删除其他世界、角色、剧情、用户或其他数据库。算法及使用边界见[地理生成说明](geographic-generation.md)。验收包括真实地理约束、MySQL／SQLite读写、服务端私密投影及3311隔离UI重开无Worker任务。

### 0.26 产品更名与兼容验收

正式名称为“编年图志 Chronicle Cartarium”，唯一品牌定义在shared/brand.json。安装、登录、导航、教学、导出说明、网页标题、启动文案、包与发行名称必须一致。旧默认标题自动显示新名称，用户自定义标题及创作正文保留；不改密码、私有配置、项目数据和revision。新JSON/备份/更新文件名与标记要正确，旧JSON和旧归档仍能读取，旧签名启动器可升级到新版。原SQLite路径、控制指针、已有库/卷/签名密钥及旧协议别名须保留兼容，见branding-compatibility.md；不能为清除旧词而破坏数据入口。验收需包含桌面/手机、地图SVG、悬浮、账号权限与原beta.5→新beta.6独立升级。

日常操作应收敛为“选择更新包 → 备份并更新”，备份、恢复验证和切换自动执行，不要求普通用户理解数据库或搬动文件。完整备份可独立创建/下载；包含私有凭据时明确告知并要求主管理员重认证。以下UPD-01/02/04及同格式离线更新已实现并有Windows/SQLite演练，MySQL完整副本恢复另有实测；UPD-03跨schema迁移校验和、UPD-05在线发布与服务/Docker实机、UPD-07断电矩阵仍待完成。

## 2. 核心用户旅程

1. GM 创建世界，填写名称、简介和所用规则。
2. 从地点或角色开始写，按需补充文化、历史、经济等设定。
3. 生成世界地图，绘制道路与河流，在城镇位置增加标记并进入详细地图。
4. 为人物上传立绘，建立人物或组织之间的关系。
5. 编排剧情节点和连线，设置变量、解锁条件与执行效果。
6. 带团时通过搜索和悬浮摘要迅速查资料，记录当次会话。
7. 导出部分设定给玩家或导出全部资料归档；换电脑时恢复数据库和资源。

## 4. 词条悬浮框与三级地图交互

### 4.1 可锁定的词条悬浮框

将鼠标移到已关联词条上，或用键盘将焦点移到链接，连续停留1000ms后显示摘要卡片；等待期间移走取消显示。卡片出现后，锁图标才开始约2700ms的填充过程，达到时限后锁定。未锁定时移走会关闭，链接到卡片之间保留120ms移入缓冲；锁定后可将鼠标移到其他地方继续查阅。不需要Ctrl/Meta。

锁定卡片内的 `[[词条名]]` 按同世界规则解析，并可继续展开和锁定下一层卡片。子卡片拥有自己的1000ms显示等待及显示后的2700ms锁定过程；点击全部可见卡片之外、窗口失焦或按Esc，清理当前悬浮集合及所有待显示计时器，释放Ctrl/Meta不关闭。悬浮状态是临时阅读状态，不存入数据库。摘要只使用服务端已授权返回的条目，不能绕过多用户权限裁剪。

### 4.2 地图由浅入深

三个级别共享同一张地图，区别在工具数量与自动化程度，不创建三份互不兼容的地图。切换级别本身不删除笔画、区域、独立组件或标记。

| 级别              | 用户操作                                                           | 自动化和控制范围                                                                                   |
| ----------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| 快速生成 `sketch` | 选少量地形颜色，在画布上涂出海陆、森林、山地等大致分布。           | 根据语义色块与种子生成边界变化和适配符号，优先快速获得可用草图。                                   |
| 智能塑形 `sculpt` | 选择局部区域、改地形类别和生成参数，使用群组组件补充景观与聚落。   | 水域、草原、森林、山地、沙漠、沼泽、雪原七类地形；区域独立种子、密度和边缘起伏，保留局部自动生成。 |
| 精细编辑 `detail` | 直接编辑图章、线条、多边形和文字，调整坐标控制点、视觉参数与排列。 | 支持把现有生成内容转成独立矢量对象；之后按对象手动修改，不再由原区域参数自动覆盖。                 |

组件库采用本项目原创的 65 种矢量符号，分为自然地貌、聚落建筑、防御设施、信仰圣地、魔法奇迹、冒险危险、资源交通七类，提供分类和中文名称搜索。涵盖原有地貌与城镇，以及旅店、酒馆、集市、修道院、法师塔、传送门、龙巢、地下城入口、磨坊、矿井、码头等。不得复制竞品的商业素材库。原有标记、道路、河流、自由笔画、父子地图、撤销重做与 SVG 下载继续可用。

“转为独立对象”是显式转换操作，转换随机底图、程序化区域与旧笔画，保留语义标记及关联；必须说明会增加对象数量，在超过容量前拒绝转换，不能只转换一部分而静默丢失内容。撤销历史仅在当前地图编辑会话中存在，持久化的是地图结果。精细编辑提供当前 SVG 对象模型范围内的直接控制，并不声称具备专业 GIS、图像编辑、气候/地质模拟或任意第三方底图的全部能力。

转换以可编辑几何和内容为目标，界面需说明它不是逐像素无损转换：旧式纹理、海岸光晕和虚线装饰不会完整复现，曲线通过采样进入控制点模型。保留原外观可在转换前导出 SVG。

图层从下至上为随机底图、底图对象、程序化地形区域、细节对象、旧式自由笔画与标记。对象可以切换底图/细节层，在同一层内调整排列；转换后的对象进入底图层，允许继续在上面增加地形。再次转换应按当前绘制顺序收集内容，不把旧背景盖到后来添加的区域或笔画上。

## 5. 世界设定模板

### 自定义字段模板（2026-10-12）

知识库、角色档案及设定条目页右上提供“模板设置”，覆盖13类设定。按当前世界和类型保存各自字段列表，支持新增、改名、移除、上下排序、恢复默认，名称1–200字符且不能重复、包含控制字符或保留名称；每种最多100项。未设置的旧世界继承默认字段，显式空列表表示没有通用字段。

应用时模板和同类已有条目的档案一起进入revision事务。新增项补空值，改名迁移内容；删除空字段，已填写的移出项保留为“条目额外字段”。与已有额外字段冲突且双方内容不同时拒绝整次修改，不能覆盖资料。其他世界、其他类型不受影响；模板取消零写入。新增角色、其他设定、切换类型和地图内国家/文化/信仰快捷创建共用模板。条目编辑期间先保存或取消本地草稿，再修改通用模板。

本地SQLite与MySQL保存完整模板；JSON备份/恢复保留定义，旧备份仍可读取。GM Markdown按所选类型导出自定义字段列表，公开导出只包含所选公开条目的实际档案值。应用后明确提示自动保存，失败显示错误，等待“所有更改已保存”才表示落盘；桌面/390px可操作。MySQL迁移004仅在项目专用库增加world.entity_templates可空JSON，不重写旧世界或revision。

## 6. 半自动剧情语义

- 世界变量采用明确名称和值，例如 `警戒度 = 2`、`已获通行证 = 是`。
- 一个节点可配置若干条件，以“全部满足”或“任一满足”组合。无条件的节点不因空列表变成永远不可用。
- 比较仅使用白名单运算符；数字比较先判断有效数值；不允许 `eval`、任意脚本或 SQL 片段。
- 节点完成时应用显式赋值效果，例如 `警戒度 = 3`。效果是赋值，不是未经说明的脚本表达式。
- 有向边表示剧情先后关系；条件表示世界状态。无入边节点可独立开始；有入边时至少一个前驱完成才可解锁，再检查变量条件。“全部/任一”仅控制条件列表，不表示必须完成全部前驱。
- GM 决定何时执行；变更变量后可以重新评估。未知变量、错拼名称、不可达分支应有可理解反馈。

## 7. 数据与部署要求

- 正式服务：Node.js + TypeScript，安装时选择本地 SQLite 或 MySQL 8；以 HTTP API 提供浏览器访问，可通过 Docker Compose 部署。
- **用户硬性约束：必须创建一个全新的独立数据库，不能修改、复用、删除或迁移服务器上任何现有数据库。** 首次部署先确定未占用的新库名；应用连接、DDL、迁移和业务写入全部限定在该新库中。不得以清空旧库的方式“初始化”。
- 数据明确区分世界、条目、地图、地图标记、笔画、关系、剧情、节点、边、变量、会话与上传资源。
- 地图的可选 `editor` 保存编辑级别、底图显隐、区域和独立对象；区域拥有局部种子，对象拥有几何与视觉参数。旧地图不必先人工升级。MySQL 增量迁移添加可空 JSON 列，不能以重建数据库实现升级。
- 实体有稳定 ID，结构性引用以 ID 储存；名称型 Wiki 引用按当前世界解析。同世界条目名称唯一，改名需同步该世界的 Wiki 引用。
- 写入校验引用存在性和世界归属，关联删除有规则；使用事务保证一次保存的原子性。
- 用 revision 防止多个标签页或设备静默互相覆盖；冲突必须由用户决定重载或保留自己的副本。
- 用户输入不能直接拼接 SQL；正文不执行 HTML 脚本；上传有类型、大小与路径限制。
- 本地演示模式必须明确标记。演示存储不是生产 MySQL 的替代品。
- 备份覆盖数据库、上传目录与环境配置。密码不进入 Git 或交接文档。

## 8. 界面与易用性

- 统一的世界导航、稳定侧栏和清楚的模块入口；编辑区、图形画布和详情面板各有明确作用。
- 中文优先，术语统一。设定、地图、角色、关系、剧情、会话、导出可直接理解。
- 以留白、排版、层级和一致配色获得美观；正文对比度与编辑密度优先于装饰。
- 图形工具在桌面提供足够空间；窄屏至少可阅读与导航，不承诺手机上具备桌面同等绘图体验。
- 点击跳转与延时悬浮摘要并存；显示等待、锁定进度及关闭方式可见，锁定卡片支持继续查词条。摘要无需快捷键，核心功能保留可见操作入口。
- 长时间创作时始终看得见保存状态；危险替换、删除与恢复操作说明影响范围。

## 9. 开发交接要求

持续维护需求、研究、架构、开发日志、交接入口。每个有意义的修改记录：日期、目的、涉及模块、决策、验证结果与遗留问题。验证结果区分“代码存在”“自动化通过”“浏览器实测”“真实 MySQL/部署验证”。新电脑首先阅读交接文档，不依赖历史聊天记录。

## 0.19 生产测试版补充验收

- 地图全屏仅包含画布与退出入口，绘制工具、上方选项和右面板不进入全屏；默认阅读平移，绘画不会在全屏误触发。
